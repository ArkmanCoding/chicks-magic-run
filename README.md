## 🇬🇧 English Description

### 📝 Overview
**Chick's Magic Run** is an interactive 2D game built using pure web technologies. This project demonstrates advanced use of HTML5 Canvas, JavaScript logic, and game physics. It was developed both as a portfolio piece and as an educational tool for programming students.

### 🚀 Key Features
- **Smooth Gameplay:** Optimized frame rates using requestAnimationFrame.
- **Physics Engine:** Real-time gravity, jumping, and collision detection.
- **Score System:** Tracks current score, collected diamonds, and saves "High Score" in LocalStorage.
- **Audio Feedback:** Dynamic sound effects for a better user experience.
- **Mobile Friendly:** Designed to be playable on different screen sizes.

### 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Graphics:** HTML5 Canvas API
- **Persistence:** LocalStorage API
- **Audio:** Web Audio API

## 🇮🇷 توضیحات فارسی

### 📝 درباره پروژه
بازی **Chick's Magic Run** یک پروژه تعاملی دو بعدی است که با تکنولوژی‌های خالص وب ساخته شده است. این پروژه قدرت HTML5 Canvas و منطق JavaScript را در پیاده‌سازی فیزیک بازی و انیمیشن‌ها نشان می‌دهد. این بازی با هدف نمایش در رزومه شخصی و همچنین به عنوان یک ابزار کمک‌آموزشی برای هنرجویان برنامه‌نویسی کانون توسعه یافته است.

### 🚀 ویژگی‌های کلیدی
- **گیم‌پلی روان:** بهینه‌سازی شده برای نرخ فریم بالا.
- **موتور فیزیک:** پیاده‌سازی جاذبه، پرش دوتایی و تشخیص برخورد (Collision Detection).
- **سیستم امتیازدهی:** ثبت امتیاز، جمع‌آوری الماس و ذخیره رکورد در حافظه مرورگر (LocalStorage).
- **صداگذاری:** دارای جلوه‌های صوتی داینامیک برای تعامل بهتر کاربر.
- **کد تمیز:** معماری ساده و قابل فهم برای مقاصد آموزشی.

### 🛠 ابزارهای استفاده شده
- **فرانت‌اند:** HTML5, CSS3, JavaScript
- **گرافیک:** HTML5 Canvas API
- **ذخیره‌سازی:** LocalStorage API
