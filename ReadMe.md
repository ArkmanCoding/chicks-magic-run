# Chick's Magic Run

A cute and interactive canvas-based endless runner game built with HTML, CSS, and JavaScript.

## Features
- Endless runner gameplay
- Score and best score tracking
- Diamond collection
- Double jump system
- Sound effects
- Restart and reset buttons
- Local storage for best score

## Technologies Used
- HTML5 Canvas
- CSS3
- JavaScript
- Web Audio API
- LocalStorage

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Play the game
